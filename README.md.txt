# PrésenceManager

Application Android (Kotlin + XML) destinée à faciliter la gestion des présences des stagiaires dans un établissement de formation.

## TP01 — Interface d'accueil

Ce premier TP consiste à concevoir l'écran d'accueil (`MainActivity` / `activity_main.xml`) :

- logo de l'application
- titre « PrésenceManager »
- description de l'application
- bouton « Commencer l'appel » (la navigation sera ajoutée dans les prochains TP)
- pied de page « PrésenceManager - Version 1.0 »

**Technologies :** Kotlin, XML, LinearLayout
